YouTube login — import from this phone

Signing in to YouTube on your phone does not automatically sign yt-dlp in on the server. Export a Netscape cookies.txt file from the same mobile browser, then select that file here. The Clipper saves it privately and uses it for video information and downloads.

Android steps (Firefox)

  1. Install Firefox for Android and sign in to YouTube in Firefox.
  2. In Firefox, open the cookies.txt add-on page and add the extension.
  3. While signed in, open youtube.com in that same Firefox browser. Use the add-on to export cookies in Netscape format and save the downloaded cookies.txt file to your phone.
  4. Return to this Clipper page in Firefox, tap Choose File below, select the downloaded cookies.txt, and tap Save cookies privately.

The add-on needs browser cookie access to export your session. Export only your own account, keep the file private, and delete the downloaded copy from your phone after a successful upload. Never send the file to anyone or paste its contents into chat. If you prefer not to grant an extension cookie access, use a desktop export instead.

Optional desktop browser connector

The companion extension can send the active video's URL to Clipper. It does not read or transfer browser cookies. For authenticated downloads, use the private cookie upload above.
