# Hermes YouTube Highlight Clipper

A small, optional CLI utility for creating short highlight videos from YouTube sources that you own or are authorized to download and repurpose. It does not alter the Hermes agent runtime or install dependencies into the main application.

## Requirements

- Python 3.10+
- `yt-dlp`
- `ffmpeg` (with libx264 and the subtitles filter)
- Optional for transcript selection and captions: `openai-whisper` and its system dependencies (including FFmpeg)

Install the command-line dependencies:

```bash
python -m pip install -U yt-dlp
# Optional AI transcription:
python -m pip install -U openai-whisper
```

Install FFmpeg using your operating system's package manager and confirm `ffmpeg -version` works.

## Usage

Run from the repository root:

```bash
python hermes/tools/video_clipper.py "https://www.youtube.com/watch?v=VIDEO_ID" --mode transcript --aspect 9:16 --limit 6 --out ./clips
```

Modes:

- `transcript` (default): uses Whisper transcript segments and a lightweight highlight heuristic (emphasis words, sentence length, punctuation). It is automatic selection, not a claim of human-level semantic understanding.
- `chapters`: uses YouTube chapter ranges that fit the requested duration.
- `manual`: cuts exact timestamps supplied by you.

Examples:

```bash
# Chapter-based horizontal clips
python hermes/tools/video_clipper.py "$URL" --mode chapters --aspect 16:9 --min-duration 20 --max-duration 90

# Manual vertical clips (timestamps may be HH:MM:SS, MM:SS, or seconds)
python hermes/tools/video_clipper.py "$URL" --mode manual --segment 00:01:15-00:02:00 --segment 00:04:10-00:04:45

# Transcript selection with burned-in captions
python hermes/tools/video_clipper.py "$URL" --mode transcript --captions --whisper-model small
```

The output folder contains MP4 clips and a `clips.json` manifest. Vertical and square modes center-crop the source; they do not perform face tracking or speaker-aware reframing. Captions are generated by Whisper and burned into each selected clip when `--captions` is enabled.

## Notes

- Use only content you own or have permission to download, edit, and publish. Respect copyright, platform terms, and any applicable local law.
- The tool runs locally; no video or transcript is sent to a hosted LLM.
- Transcript mode requires Whisper to be installed. Use `--mode chapters` or `--mode manual` without it.
- If a video has no chapters, chapter mode reports that no suitable segments were found.
- The first run of Whisper may download its selected speech-recognition model.
- This is a standalone tool, not yet wired into the Hermes web dashboard or agent tool registry.
